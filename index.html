通过 Supabase 免费实现多设备数据同步。
数据存储在你自己的 Supabase 项目中，邮箱登录后自动同步。
📝 如何配置 Supabase 同步？（点击展开教程）
第 1 步 — 新建项目：
访问 supabase.com，注册并新建一个项目（免费额度即可）。
第 2 步 — 获取 URL 和 anon key：
进入项目 Settings → API，复制 Project URL 和 anon public 密钥。
第 3 步 — 建表（SQL Editor 执行）：
create table app_data (user_id uuid primary key references auth.users(id), data jsonb not null, updated_at timestamptz default now());
alter table app_data enable row level security;
create policy "读写自己的数据" on app_data for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
第 4 步 — 开启邮箱登录并建账号：
进入 Authentication → Providers → Email 确认已启用；再到 Authentication → Users 点 Add user，填邮箱和密码创建账号。
第 5 步 — 把 URL、anon key、邮箱、密码填入本表单，点保存即可。多台设备用同一账号登录即自动同步。
