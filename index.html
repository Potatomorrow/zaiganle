通过 Supabase 免费实现多设备数据同步。
只需填写项目 URL 和 anon key，即可自动同步；多台设备用同一配置即可互通数据。
📝 如何配置 Supabase 同步？（点击展开教程）
第 1 步 — 新建项目：
访问 supabase.com，注册并新建一个项目（免费额度即可）。
第 2 步 — 获取 URL 和 anon key：
进入项目 Settings → API，复制 Project URL 和 anon public 密钥。
第 3 步 — 建表（SQL Editor 执行）：
create table app_data (sync_key text primary key default 'main', data jsonb not null, updated_at timestamptz default now());
第 4 步 — 关闭 RLS（或开放策略，SQL Editor 执行）：
alter table app_data disable row level security;
（此方案无需邮箱登录，建议使用独立的 Supabase 项目专门存放工作台数据，避免与其他业务混用。）
第 5 步 — 把 URL 和 anon key 填入本表单，点保存即可。多台设备用同一配置即可自动同步。
